 <strong>Simulation</strong> - Control simulation execution and tune variable, block parameter, and model parameter values
    The Simulation object represents a simulation of a model and provides an
    interface to control the simulation.

    <strong>Creation</strong>
      <strong>Syntax</strong>
        s = simulation(mdlname)
        s = simulation(simin)

      <strong>Input Arguments</strong>

    <strong>Object Functions</strong>
      Control Simulation Execution
        <a href="matlab:help initialize -displayBanner">initialize</a> - Initialize simulation represented by Simulation object
        <a href="matlab:help simulink.Simulation.start -displayBanner">start</a>      - Start simulation represented by Simulation object
        <a href="matlab:help simulink.Simulation.step -displayBanner">step</a>       - Advance simulation represented by Simulation object by specified amount
        <a href="matlab:help simulink.Simulation.pause -displayBanner">pause</a>      - Pause active simulation represented by Simulation object
        <a href="matlab:help simulink.Simulation.resume -displayBanner">resume</a>     - Continue paused simulation represented by Simulation object
        <a href="matlab:help simulink.Simulation.stop -displayBanner">stop</a>       - Stop simulation represented by Simulation object
        <a href="matlab:help simulink.Simulation.terminate -displayBanner">terminate</a>  - Terminate simulation represented by Simulation object

      Configure Simulation
        <a href="matlab:help setExternalInput -displayBanner">setExternalInput</a>  - Specify external input data for top-level input ports using SimulationInput or Simulation object
        <a href="matlab:help setInitialState -displayBanner">setInitialState</a>   - Specify initial state for simulation using SimulationInput or Simulation object
        <a href="matlab:help setVariable -displayBanner">setVariable</a>       - Set variable values for simulation using SimulationInput or Simulation object
        <a href="matlab:help setModelParameter -displayBanner">setModelParameter</a> - Set model parameter values for simulation using Simulink.SimulationInput or Simulation object
        <a href="matlab:help setBlockParameter -displayBanner">setBlockParameter</a> - Set block parameter values for simulation using SimulationInput or Simulation object

      Tune Parameter and Variable Values During Simulation
        <a href="matlab:help setVariable -displayBanner">setVariable</a>       - Set variable values for simulation using SimulationInput or Simulation object
        <a href="matlab:help setModelParameter -displayBanner">setModelParameter</a> - Set model parameter values for simulation using Simulink.SimulationInput or Simulation object
        <a href="matlab:help setBlockParameter -displayBanner">setBlockParameter</a> - Set block parameter values for simulation using SimulationInput or Simulation object
