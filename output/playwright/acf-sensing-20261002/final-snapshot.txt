        - paragraph [ref=f1e232]: The controller estimates local normal direction from tool motion without receiving the bump geometry.       - generic [ref=f1e235]:
        - heading "Control and robot recentering" [level=2] [ref=f1e236]
        - paragraph [ref=f1e237]: The fast loop regulates reconstructed normal force. A PI/PID correction combines with gravity compensation, measured-acceleration feedforward and a measured correction for surface slope and sanding drag. The two-state motion observer estimates S–A separation and velocity from relative position, measured S acceleration and the causal robot-motion predictor. With upper A rigidly attached to the prescribed robot boundary, these give an estimate of the tool's axial velocity and therefore local surface slope. An upper compliant attachment needs an additional estimate of A's motion before this reconstruction can be qualified.
        - paragraph [ref=f1e238]: "The geometry feedforward uses an estimated ratio of tangential drag to pressing force. From the reconstructed reaction vector and estimated slope:"
        - code [ref=f1e240]: mu_hat_raw = −(Rx_hat + s_hat Rz_hat) / (Rz_hat − s_hat Rx_hat) Rz_request = Nref (1 − mu_hat s_hat) / sqrt(1+s_hat²)
        - paragraph [ref=f1e241]: The ratio is accepted only while estimated pressing force and the denominator exceed 1 N, is bounded to [−1,1], and is smoothed with a 5 ms EMA. It starts at zero and holds its previous value when invalid. This supplies measured drag compensation without assuming that the controller knows the plant's friction coefficient. A radial fluctuation of reaction force cancels in the ratio, which helps avoid turning geometry feedforward into an additional high-frequency force-feedback path. Force reconstruction itself still uses the measured vector projected onto the estimated normal.
        - paragraph [ref=f1e242]:
          - text: For an identified coil force constant Kf and positive error
          - code [ref=f1e243]: e = Nhat − Nref
          - text: ", the main current request is:"
        - code [ref=f1e245]: Irequest = Ih_hold + (Rz_request − Nref)/Kf − (mB_identified + mS_identified) aS_FF/Kf + friction_estimate(vgap_hat)/Kf + lower_inverse_current + feedback_filter(−Kp e − Ki integral(e) − Kd derivative_filtered(e))
        - paragraph [ref=f1e246]: The measured-acceleration term corrects the disturbance after it is observed. It supplies no future surface information. A separate optional causal derivative lead and feedforward filter trade transient delay against amplification of accelerometer noise. The identified masses and force constant determine these commands; the physical plant retains its actual masses, winding and force constant. Saturation and antiwindup keep the integrator consistent with available current. PI gains are expressed explicitly in A/N and A/(N·s); changing Kf does not silently change user gains.
        - paragraph [ref=f1e247]: "The coil's own current regulator retains winding resistance, inductance, back EMF and supply clipping. Actual current follows its physical winding state, rather than jumping instantly to the request. The force loop and current loop are separate: a fast software update does not establish either loop's physical bandwidth."
        - paragraph [ref=f1e248]: Fast feedback and feedforward have different filtering needs. Feedback must avoid exciting delayed structural modes; feedforward needs to follow the tool's measured acceleration promptly. Filtering the entire current request can stabilize a mode while also delaying the useful acceleration correction. The structural controller search therefore examines both total-current mode suppression and filtering of the feedback correction alone, with the same physical sensor inputs. Every selected filter must be tested with repeated bumps and changed structural frequency, rather than accepted from one quiet trace.
        - paragraph [ref=f1e249]: "The robot loop recenters actuator travel slowly. Its output should not chase a 0.1 s bump through a delayed industrial robot. The existing gate checks reconstructed force error within ±0.2 N, filtered trend within 2 N/s and a 100 ms stable interval. A second detector evaluates force variation at every 10 kHz force sample: a 100 ms error mean, 20 ms fluctuation-variance filter and an 0.08 N RMS threshold. Every failing fast sample resets the stable dwell, including threshold crossings between robot ticks. Robot commands are issued at 100 Hz only after the dwell is complete. These thresholds are explicit control settings, rather than a promise that filtered force alone bounds the true workpiece force."
        - paragraph [ref=f1e250]: The requested recenter gain is bounded using expected robot delay, response time and gate timing. For the modeled 80 ms command delay, 60 ms response and two 100 ms gate intervals, an 0.8/s request is capped at approximately 0.735/s. A physical robot still needs a measured loaded response before accepting this gain.
        - paragraph [ref=f1e251]: Closing the gate suppresses new correction commands. It cannot cancel commands already in a delay queue. The command predictor therefore models already-issued motion; it is not a preview of future bumps. The selected recordings test that distinction explicitly.
        - paragraph [ref=f1e252]: The prescribed-motion robot model is suitable for studying command delay and stroke management. It does not yet represent force-induced robot compliance, joint dynamics or a controller that changes its own behavior under load. Those properties require measurements of the actual robot and a low-gain prototype recenter test before increasing correction gain.

        - heading "What the model does and does not establish" [level=2] [ref=f1e1608]
        - paragraph [ref=f1e1609]: The model calculates force balances, explicit rigid constraints, spring/damper loads, stroke, actuator current and voltage, sensor filtering/noise/delay, causal estimation, fast force control and slow delayed robot recentering.         - paragraph [ref=f1e1610]: It represents translational point contact in a scanning plane. A real sanding pad distributes pressure over an area and deforms.
